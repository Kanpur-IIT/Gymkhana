### 🏛️ Students' Gymkhana – IIT Kanpur

यह **IIT Kanpur Students' Gymkhana** की आधिकारिक वेबसाइट का सोर्स कोड है। यह प्रोजेक्ट मुख्य रूप से HTML, CSS और JavaScript का उपयोग करके बनाया गया है और इसे लाइव होस्ट करने के लिए Vercel प्लेटफ़ॉर्म का उपयोग किया गया है। 

### 🌐 लाइव लिंक्स (Live Links)

* **लाइव वेबसाइट:** [https://gymkhanaiitk.vercel.app/](https://gymkhanaiitk.vercel.app/)
* **गिटहब रिपोजिटरी:** [https://github.com/Kanpur-IIT/Gymkhana](https://github.com/Kanpur-IIT/Gymkhana)

### 🎯 मुख्य अनुभाग (Website Sections)

इस वेबसाइट में स्टूडेंट्स जिम्खाना के सभी प्रमुख अंगों को दर्शाया गया है: 

* **Councils:** Academic and Research (AnC), Games and Sports (GnS), Media and Culture (MnC), Science and Technology (SnT)।
* **Cells:** CWC, EC, E-Cell, Outreach, Vox।
* **Fests:** Antaragni (अन्तराग्नि), Techkriti (तकनीकी), Udghosh (उद्घोष)।
* **Other Features:** Students' Senate, Hostels, Gallery, Awaaz IITK (शिकायत निवारण)।

### 🛠️ तकनीकी विवरण (Tech Stack)

* **Frontend:** HTML5, CSS3, JavaScript
* **Hosting & Deployment:** Vercel
